## 第 9 条　为什么内存这么小

- **需求解读**：对内存占用数据提出质疑。
- **交付物**：复核后主动纠正自己的错报：47.6 MB 只是宿主进程，实际为 7 个进程合计约 424–470 MB。
- **验证与修复**：同时纠正此前「32 个内核进程」的说法——那是按进程名全机统计，属于本应用的只有 6 个。
- **备注**：结论如实说明：节省的是磁盘（3 MB vs 需自带 Chromium），内存并不比同类方案低。

## 第 12 条　手机电脑两用板

- **需求解读**：要求同一产品在手机与电脑上都能用。
- **交付物**：探明本机无 Java / Android SDK 后，手机端定为 PWA 路线：manifest、Service Worker 离线缓存、安装图标；桌面版内建只读内网服务（TcpListener 手写，避免管理员权限），供手机扫码访问。
- **验证与修复**：内网服务经安全校验：5 种目录穿越（含编码变体）全部 403、写操作 405、响应体与源文件逐字节一致。
- **备注**：手机与电脑数据各自独立，不做同步，文档中已写明；随后另有一条「要」——回应我上一轮末尾关于二维码的提议：自研零依赖 QR 编码器（字节模式、纠错等级 L、版本 1–4 自动择版、8 种掩码按规范罚分择优），实现扫码即开，免去手输 IP。

## 第 13 条　手机是能安装成APP，并且官方浏览器均可使用

- **需求解读**：手机上要能安装成应用，且各官方浏览器都要正常。
- **交付物**：排查出会破坏界面的兼容缺陷：22 处 color-mix()（需 Chrome 111+ / Safari 16.2+）在国产内核上会全部失效，改为 rgba 变量配色；并实现分平台安装引导（含 iOS 分享菜单、微信内置浏览器的处理）。
- **验证与修复**：视觉回归核对配色计算值全部正确；390×844 设备仿真下 7 个页面零横向溢出。
- **备注**：同时修正我此前「局域网 http 无法安装」的不完整说法：iOS 在 http 下即可添加到主屏幕。

## 第 14 条　vivo

## 第 15 条　做成APK

- **需求解读**：要一个能真正安装到手机上的安卓安装包，而不是网页快捷方式。
- **交付物**：从零获取 JDK 17 与 Android SDK（build-tools r34 + platform 34），不使用 Gradle 手工构建：aapt2 compile/link → javac → d8 → 自行写入 assets → zipalign → apksigner；产出 218 KB 的校园通.apk 及安装说明。
- **验证与修复**：静态校验全部通过：清单（minSdk 21 / targetSdk 34 / 三项权限 / 中文应用名 / 自适应图标）、dex 类清单、assets 条目名、签名 v1+v2+v3、4 字节对齐；服务逻辑在桌面用文件系统桩实测（响应体与源文件逐字节一致、5 种目录穿越全部 404）。
- **备注**：修复四个真实坑：aapt2 在 Windows 上把 assets 条目标成反斜杠（真机会全部 404）、apksigner 需要 JAVA_HOME、keytool 的正常信息走 stderr 被误判为致命错误、重复打开同一 zip 导致 IOException。受环境所限（无安卓设备与模拟器镜像）未在真机运行验证，该限制已写入产品承诺书。

## 阶段归纳

- **第一阶段 · 功能定义（第 1–2 条）**：从四个模块的清单，细化为「课表与教室合并」「带政策、教师与电话的问答」「带图片智能匹配的失物招领」「按位置推荐教室」三项明确需求。
- **第二阶段 · 实现与验证（第 3–6 条）**：完成全部业务逻辑、自测体系与渲染核对；产出网页版并确认其运行方式。
- **第三阶段 · 形态升级（第 7–8 条、第 12–15 条）**：网页 → Windows 桌面软件 → 手机与电脑两用（PWA + 内网共享 + 二维码扫码）→ 安卓 APK（不用 Gradle 手工构建）；每次升级都要求真跑起来，而不是停留在界面演示。
- **第四阶段 · 质量复盘（第 9–11 条）**：对内存数据提出质疑后复核纠错，随后放弃该项优化，转而用远程调试驱动真实窗口完成端到端验收，并整理发布包。
- **贯穿全程的验证原则**：不声称已验证，除非给出可复现的命令与结果；遇到不确定的 API 先确认真实签名再动手；每修一个缺陷补一条能捕获它的测试。

> 说明：本记录覆盖第 1–15 条，即从需求定义到安卓安装包完成的开发全程。此后的材料整理阶段（产品承诺书、AI 提示词集）不属于产品开发指令，另行成文。
