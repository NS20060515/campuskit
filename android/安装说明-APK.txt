校园通 · 安卓版（APK）安装说明
========================================

文件名：校园通.apk
大小  ：约 0.6 MB（含高德地图底图 437 KB）
系统  ：Android 5.0（API 21）及以上，实测签名覆盖 Android 5.0 ~ 14+
特点  ：网页资源全部打包在 APK 内，安装后**完全离线可用**，不联网也能用

----------------------------------------
一、怎么装到手机上
----------------------------------------
方式一（推荐，用数据线或微信/QQ 传文件）
  1. 把「校园通.apk」传到手机（微信「文件传输助手」、QQ、数据线拷贝都可以）；
  2. 在手机上点开这个文件；
  3. 系统会提示「为了安全，你的手机不允许安装未知来源应用」——
     点「设置」→ 允许该来源安装 → 返回后继续；
  4. 若出现「Play 保护机制」或手机管家提示风险，选择「仍要安装 / 继续安装」；
     （原因见下面「关于签名」，这是自签名应用的正常提示，不是病毒）
  5. 装好后桌面会出现「校园通」图标（紫色渐变 + 白色「校」字）。

方式二（用电脑通过 adb 安装，适合开发者）
  adb install -r 校园通.apk

----------------------------------------
二、安装后的使用
----------------------------------------
· 打开即用，三块功能与电脑版完全一致：
    课表 · 教室（含空闲教室矩阵、社团活动、按位置推荐最近教室）
    失物招领（含照片上传与端侧智能匹配）
    校园问答（问答广场、政策与办事指南、校园通讯录）
· 首次点「空闲教室 → 使用设备定位」时，系统会弹出定位权限申请，
  允许后才会读取位置；拒绝也不影响使用，可手动选择「我的位置」。
· 数据保存在应用自己的存储里，与电脑版互不相通（没有后端同步）。
· 底部返回键：在页面内返回上一级，回到首页后再按才退出应用。

----------------------------------------
三、技术实现（与"简单套壳"的区别）
----------------------------------------
· 不是直接把 file:///android_asset 丢给 WebView：那样属于「不安全来源」，
  localStorage 受限、Service Worker 被禁用、定位会被拒绝。
· 本应用内置一个只读的回环 HTTP 服务（AssetServer），把打包的网页
  通过 http://127.0.0.1:随机端口 发布，WebView 因此处于「安全上下文」，
  与正式网站行为完全一致；服务启动失败会自动退回 file:// 方式。
· 回环服务只绑定 127.0.0.1、只支持 GET、只读、带目录穿越防护；
  清单里用 network_security_config 仅对回环地址放行明文 HTTP。
· 支持网页里的 <input type="file"> 选照片（onShowFileChooser），
  所以失物招领的「上传照片 → 智能匹配」在 APK 里可以正常用。
· 自适应图标（Android 8+ 圆形/方形裁切）+ 旧版多密度图标。
· 未申请任何多余权限：只有网络（回环服务需要）、粗略/精确位置。

----------------------------------------
四、关于签名（重要）
----------------------------------------
本 APK 使用**自签名证书**（CN=CampusKit）签名，签名方案覆盖 v1 + v2 + v3，
因此在 Android 5.0 到 14+ 都能正常安装。

因为不是通过应用商店分发，手机管家或 Play 保护机制可能给出
「未知来源」「可能有害」之类的提示——这是所有自签名 APK 的通用提示，
选择继续安装即可。

若要正式上架应用商店，需要用你自己的发布密钥重新签名：
    powershell -File build.ps1 -Release
（会在 build 目录生成 release.keystore，请务必备份并妥善保管，
  丢失后无法再发布同一应用的更新）

五、诚实说明：验证到了哪一步
----------------------------------------
本机没有安卓设备，也没有模拟器镜像（无法安装 system-image 与硬件加速），
因此**没有在真机上跑过**。已经完成的验证是：

  ✅ 清单解析：包名 com.campushub.app、minSdk 21 / targetSdk 34、
              权限、中文应用名、自适应图标、启动 Activity 全部正确
  ✅ dex 内容：MainActivity / AssetServer 及其内部类均已编译进包
  ✅ 资源完整：assets 下 20 个网页文件条目名均为正斜杠
              （aapt2 在 Windows 上会写成反斜杠，那样真机会全部 404，
                已改为自行打包规避）
  ✅ 签名校验：v1 / v2 / v3 三种方案全部通过；zipalign 4 字节对齐通过
  ✅ 服务逻辑：把同一份 AssetServer 代码在桌面上用文件系统跑通，
              MIME 类型、404、逐字节一致（8357/8357 字节完全相同）、
              5 种目录穿越攻击全部 404 —— 均实测通过

首次在真机上打开时，如果出现白屏，请先确认：
  1. 手机系统为 Android 5.0 及以上；
  2. 应用有存储读写空间（数据目录需要可写，用于保存课表等修改）。
反馈问题时把现象告诉我，我可以据此定位。

----------------------------------------
六、卸载
----------------------------------------
长按桌面图标 → 卸载（或用 设置 → 应用 → 校园通 → 卸载）。
卸载后应用内保存的数据一并清除，系统里不留残留。
