校园通 CampusKit · 使用说明
========================================

一款校园服务软件，同一套界面同时支持电脑与手机。包含三大模块：
  1. 课表 · 教室 —— 周课表、空闲教室矩阵、社团活动，并按你的位置推荐最近的空教室
  2. 失物招领   —— 招领/寻物信息发布，上传照片后在本机做特征匹配，自动推送可能相关的帖子
  3. 校园问答   —— 问答广场、政策与办事指南、校园通讯录（含责任部门与联系电话）

----------------------------------------
电脑上如何运行
----------------------------------------
双击「校园通.exe」即可，无需安装、无需联网、无需管理员权限。
首次启动约需 1~2 秒（要拉起内置浏览器内核）。

----------------------------------------
手机上如何使用
----------------------------------------
【第一步 · 让它跑起来（最快，扫码即可）】
  1. 电脑上打开「校园通.exe」；
  2. 点左下角「手机访问」，会弹出一个二维码和形如 http://192.168.x.x:端口/ 的地址；
  3. 手机连到和电脑相同的 WiFi，用相机或微信「扫一扫」直接打开。

  提示：首次点击「手机访问」时，Windows 可能弹出防火墙提示，
        请勾选「专用网络」并允许，否则手机连不上（家庭网络选专用即可）。
        关闭软件后共享自动停止；同一 WiFi 下的其他设备也能访问该地址。

【第二步 · 装到手机桌面，像 App 一样用】
  iPhone / iPad（Safari、Edge、Chrome 等都可以）：
    点浏览器底部「分享」按钮 → 选择「添加到主屏幕」→ 点「添加」。
    装好后从桌面打开是独立全屏窗口，没有地址栏。
    注意：iOS 用上面那个局域网地址就能这样安装，不需要 HTTPS。

  安卓（Chrome、Edge、vivo、华为、小米、OPPO、三星、QQ、UC 等）：
    各家的菜单位置不一样，应用内会按你的浏览器给出对应提示，实测对照表：

      vivo 浏览器    底部「≡」或「更多」→「添加到桌面」
      华为浏览器     底部「≡」→「添加到桌面」
      小米浏览器     底部「≡」→「添加到桌面」
      OPPO 浏览器    底部「≡」→「添加到桌面」
      QQ / UC 浏览器 底部「≡」→「添加到桌面」
      三星浏览器     右下角「≡」→「添加页面到」→「主屏幕」
      Chrome         右上角「⋮」→「安装应用」或「添加到主屏幕」
      Edge           底部「⋯」→「添加到手机」或「安装」

    · 用 HTTPS 地址访问时：可直接「安装应用」，桌面出现图标，可离线打开；
    · 用局域网 http 地址时：安卓浏览器出于安全策略一般只允许
      「添加到桌面」创建快捷方式，不做完整安装。
      想要完整安装：把本软件的 app 目录（index.html、css、js、icons、
      manifest.webmanifest、sw.js）上传到任意 HTTPS 静态托管
      （GitHub Pages、Netlify、Vercel、Cloudflare Pages 等均可），
      手机打开该网址后再「安装应用」即可。

  微信内置浏览器：不支持安装和添加到主屏幕。
    请点右上角「⋯」→「在浏览器打开」，再用上面的方法安装。

  应用内也有入口：侧边栏「安装到桌面」按钮（手机上会自动弹出提示条），
  会按你当前设备和浏览器给出对应的操作步骤。

【手机端有什么不同】
  · 布局自动切换为单列 + 底部标签栏，适配触屏；
  · 数据各自保存在各自设备上，手机与电脑之间不同步；
  · 设备定位需要 HTTPS 或 localhost，局域网 http 下会被浏览器禁用，
    此时可手动选择「我的位置」，推荐功能照常工作。

----------------------------------------
浏览器兼容性
----------------------------------------
界面刻意避开了新语法，以适配国产浏览器内核（vivo、华为、小米、OPPO、
三星、QQ、UC、微信内置常见 Chromium 86–108）：

  · 所有浅色底与描边改用 CSS 变量 + rgba 计算，不再使用 color-mix()
    （它需要 Chrome 111+ / Safari 16.2+，在这些浏览器上会让配色整体失效）
  · 弹层遮罩与上传热区由 inset 简写改为 top/right/bottom/left 四向展开
    （inset 需要 Chrome 87+，老内核下弹层会塌成 0 尺寸、无法点击）
  · backdrop-filter 补了 -webkit- 前缀；100dvh 保留 100vh 作为回退
  · JS 侧未使用 ?. / ?? / structuredClone / replaceAll / Array.flat 等新 API

以下环境均可正常显示：

  · 电脑：Chrome、Edge、Firefox、Safari（以及桌面版本内置的 Edge 内核）
  · 手机：iOS Safari、Android Chrome / Edge、vivo、华为、小米、OPPO、
          三星、QQ、UC、微信内置浏览器（Chromium 86 起）

已知差异（不影响功能）：Chromium 84 以下的极老内核不支持 flex gap，
各元素间距会显得紧凑一些；图文与操作均正常。

实测：390×844（dpr3，mobile）手机视口下 7 个页面无横向溢出；
13 种浏览器 UA 逐个验证，安装指引文案与菜单路径均对得上。

实测：390×844（dpr3，mobile）手机视口下，7 个页面均无横向溢出。

快捷键（电脑端）
----------------------------------------
  F5               刷新页面
  F11              全屏 / 退出全屏
  Esc              退出全屏
  F12 或 Ctrl+Shift+I   打开开发者工具（排查问题用）
  Ctrl + 加号 / 减号    放大 / 缩小页面
  Ctrl + 0 或 Ctrl + 1  恢复 100% 缩放

  命令行参数：可指定启动页面，便于为单个模块单独建快捷方式
    校园通.exe --page=rooms      空闲教室
    校园通.exe --page=match      失物智能匹配
    校园通.exe --page=contacts   校园通讯录
    （还支持 act / lost / qa / policy）

----------------------------------------
数据保存在哪里
----------------------------------------
电脑端：%LOCALAPPDATA%\CampusKit\（课表、失物、问答的修改与窗口位置）
手机端：手机浏览器自己的站点数据里。
点侧边栏左下角「恢复初始演示数据」可以随时把电脑端还原成初始状态。

----------------------------------------
关于定位功能
----------------------------------------
「空闲教室」页的「使用设备定位」按钮调用系统定位服务。
若系统未开启定位（设置 → 隐私和安全性 → 位置），会提示定位失败并自动
退回手动选择位置，其余功能不受影响。

----------------------------------------
能力边界说明（未夸大）
----------------------------------------
· 照片匹配为「端侧特征计算」：在本机提取图片主色与明暗特征，再叠加分类、
  关键词、地点、时间做加权打分；未接入云端视觉大模型。
· 校园坐标为演示用虚拟坐标，距离按直线距离与步行速度折算。
· 教室占用中，本人的课程与社团活动为真实数据，其余「其他班级」占用为
  演示生成的稳定数据（同一天结果不会变化）。
· 政策与电话号码格式与真实一致，但为演示数据，请勿直接拨打。
· 手机端是 PWA（网页应用），不是原生安卓 APK：本机没有 Android 打包工具链
  （JDK / Android SDK），无法直接产出 APK；若确实需要 APK，可把 app 目录
  交给在线打包服务（例如 PWABuilder）生成。

----------------------------------------
运行环境
----------------------------------------
· Windows 10 / 11（64 位）
· 需要 Microsoft Edge WebView2 运行时：Win10/11 通常已自带；
  若提示缺失，到微软官网搜索「WebView2 Runtime」安装即可
· .NET Framework 4.6.2 及以上（Win10/11 自带 4.8）
· 手机端：iOS Safari 15+ / Android Chrome 90+ 等现代浏览器，
  并兼容 Chromium 86 及以上的国产浏览器内核

----------------------------------------
卸载方法
----------------------------------------
1. 双击「卸载.bat」可删除桌面/开始菜单快捷方式与本地数据；
2. 之后直接删除整个「校园通」文件夹即可，软件不在系统里留任何残留。
3. 手机上：长按桌面图标选择「移除 / 卸载」即可。
